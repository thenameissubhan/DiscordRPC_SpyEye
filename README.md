# SpyEye Discord Rich Presence

**SpyEye** is a high-performance Discord Rich Presence application designed to display authorized system, application, and gaming activity as a dynamic, real-time Discord status.

## Security Notice
Use this software only on devices you own or administer, and only with explicit consent. SpyEye is intended strictly for personal use, development, activity visualization, and streaming not covert monitoring.

---

## ✨ Overview
SpyEye transforms basic Discord presence into a dynamic, data-rich activity panel. It provides seamless background execution, GPU telemetry, system tray utilities, and customizable activity states.

---

## 🚀 Version History

| Version | Focus | Key Enhancements |
|--------|--------|------------------|
| **V1** | Foundation | Two-part system (.exe + console), basic RPC integration |
| **V2** | Streamlined | Single executable, structured logging, GPU usage & temperature |
| **V3** | Connected | Optional Telegram notifications, privacy-first design |
| **V4** | Dynamic | System tray, favicon fetching, GUI-based activity manager |

---

## 🧱 V1 — The Foundation
- Two-part architecture: `SpyEye.exe` + `SpyEyeConsole.exe`
- Basic Discord Rich Presence functionality

---

## ⚡ V2 — Enhanced & Streamlined
- Single unified executable (`SpyEye_v2.exe`)
- Advanced logs: `spyeye_error.log`, `spyeye_usage.log`
- GPU telemetry for Steam titles

---

## 🌐 V3 — Real-Time & Connected
- Optional Telegram notifications with user authentication
- Privacy-by-design remote access

---

## 🎛️ V4 — Dynamic & Customizable
- System tray background control
- Automatic favicon detection for websites
- GUI-driven custom activity configuration (no JSON editing required)

---

## ⚙️ Feature Summary
- Rich Presence for approved apps/games
- Dynamic favicon support (via SpyEye Extension)
- Custom Activity Manager GUI
- Diagnostic logging
- GPU telemetry for supported games
- Optional webhook/bot forwarding
- Lightweight, optimized for streamers & personal setups
